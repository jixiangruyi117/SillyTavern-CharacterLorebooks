# 角色世界书

一个 SillyTavern 第三方页面扩展，用于按角色归属查看已有世界书。

## 它做什么

- 从酒馆原生的角色主世界书、附加世界书和全部世界书中建立只读索引；
- 提供“当前角色 / 公共世界书 / 全部世界书”筛选；
- 标示当前角色、共享、全局已启用、聊天和人设世界书；
- 发现已绑定但文件不存在的世界书时只告警；
- 点击条目后打开酒馆原生世界书编辑器。

## 它绝不做什么

- 不创建、改名、移动、删除或覆盖世界书文件；
- 不修改角色卡数据、附加世界书配置、全局启用状态或聊天元数据；
- 不接管世界书扫描、提示词装配或其他插件 API；
- 不读取凭证，不发送网络请求。

因此它可以与现有世界书、角色、正则和提示词插件并存。酒馆仍是唯一的数据与运行时权威。

## 安装

1. 将本目录复制或克隆到 SillyTavern 的 `public/scripts/extensions/third-party/SillyTavern-CharacterLorebooks`。
2. 刷新酒馆页面，在“扩展”设置中启用“角色世界书”。
3. 展开“角色世界书”抽屉，默认只显示当前单角色聊天绑定的世界书。

当前版本为 0.1.1，已按本机 SillyTavern 1.18.0 的公开 `SillyTavern.getContext()`、事件和原生 DOM 入口实现。若酒馆升级后找不到原生世界书编辑器，插件只会提示，不会修改任何数据。
